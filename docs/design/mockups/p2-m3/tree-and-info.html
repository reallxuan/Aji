1 分支 the variation tree

Each move is a small stone. The current move has a ring. Letters mark the lines you can go into from the current move, the same letters as the board's badges. A dot above a stone means it has a comment. The try-out line is dashed, in the same amber as 试下中. A click on a stone goes to it. The tree scrolls to keep the current move in view, and draws only what is on screen, so a record with hundreds of branches stays quick.

Moves run left to right, as interface design 4.4 drew them; variations drop below where they leave. Every fifth move is numbered.

The tree takes the shape of its panel: moves run across when the panel is wider than tall, and down when it is taller than wide. Dragging the panel somewhere else turns it.

Keys: ← → and ↑ ↓ step, as today. [ and ] switch between the continuations of the current move (owner, 2026-11-23). Esc goes back to where this variation left, B goes back to the main line.

No tree, no panel. As in design 4.4, a record without variations folds the 分支 panel to nothing, and it appears with the first variation.

2 Right-click menus (long press on touch)

Interface design 6 asked for these: make main line, delete a variation, add a note. Every item can be undone, so none asks for confirmation.

上移一位 swaps a variation with the one before it, so the order of the letters can be changed without making it the main line. 编辑评论 opens the 评论 panel on that move, with the cursor in it.

On a try-out stone

保留为分支 turns the try-out into an ordinary variation, for when a line you tried turns out worth keeping. It then counts as a change, and is saved.

回到这一手 goes back to the move that placed the stone (charter 7.2). A plain click on a stone does nothing, so a stray click never moves you away (owner, 2026-11-23). 在这里试下 starts a try-out with that move, the quick way in without the button. 标记 ▸ puts one mark without switching to 标记 mode.

Letter badges (interface design 5.4, unchanged): A, B and C sit on the upper right of each continuation's point. C11 and P12 are not among KataGo's candidates, so each gets an empty outlined disc under its letter. The try-out's letter is amber, like its line in the tree.

A click on a badge goes into that line. A right-click on it opens the first menu above.

3 棋局信息 game information

The rules chip and the title open it, as since M6, and now it can be edited. Fields are edited in place; each change is one undoable step, and marks the game as changed. 结果 (SGF RE) is a choice of winner and a margin, or 中盘, 超时 or 弃权. When final scoring (M2) has a count, 填入点目结果 writes it in.
