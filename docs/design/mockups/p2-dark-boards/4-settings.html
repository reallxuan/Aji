One board per theme: how Settings shows it

Three ways to lay out Settings, then Interface, then Board style. Each mock is a 400 px settings column, the width of the default layout's right column at 1440 by 900. The sets are now six: the four of today, then 石墨 (Graphite) and 墨黑 (Ink), each with the flat stones you picked. In every mock the window is in the dark theme, the dark theme uses Graphite and the light theme keeps Honey. Click the one you prefer.

S1 Two rows

One row of tiles per theme, both always visible. Nothing is hidden, but the section is about twice as tall, and in a narrow column each row wraps.

The same in all three
  • Both themes start on Honey, so nothing changes until someone chooses. A device that started in the phone layout starts on Printed in both themes, as today.
  • Custom (the last tile) mixes a board and stones, for each theme on its own.
  • The wood-grain slider rests only when neither theme's board has grain.
  • Anyone who chose a board before this change keeps it in both themes.
