M7 · 胜率走势图 trend graph

Made-up data for a 247-move game. The user stepped through moves 0–95 with analysis running, held → through 96–110 (each position had only a few visits, too few to plot), stepped 111–130, and is now on move 130. Earlier they also jumped to the end and looked at moves 238–247. Everything else has no result yet.
  • x axis: the game's main line, move 0 to the last move, always the full length, so the graph does not rescale as more moves are analysed.
  • White line: Black's win rate on the left axis (0–100 %). Amber line: Black's score lead on the right axis, symmetric about 0 so that 0 points sits on 50 %.
  • Short bars along the bottom: mistakes, where both the position before and after a move have results.
  • Dashed line: the current move. Hover anywhere for that move's numbers; click to go there.

Chosen: A, and the lead hides itself when the leading segment is too narrow for both texts. The bar now runs the full width of the panel. 3 · Moves with no result: how to draw the gaps

A · Dotted bridge for gaps up to 20 moves, empty beyond was recommended: the shape of the game stays readable, you can still see which stretches were really analysed, and a jump to the end does not draw a line across 100 unseen moves. B · Break chosen by the owner: honest; a stretch with no results shows as empty. C · Solid line (LizzieYzy): smoothest, but straight lines across unanalysed moves look like data, worst of all across the 108 moves between 130 and 238.
