1. 一键切换（桌面）

标题栏里，引擎圆点左边加一个配置标签，显示当前配置的名字。点开是配置列表，当前的打勾，第二行是权重和速度。切换后 KataGo 重启，棋盘、图表和大损失列表只显示这个配置的结果；以前分析过的局面立刻从缓存里出来。整盘分析进行中时，切换前先问一句。

3. 设置里的引擎

配置列表，点圆圈切换。每行的 ⋯ 菜单有重命名和移除。当前配置不能移除，要先切换。移除只是从列表拿掉，不删文件；某个权重不再被任何配置使用时，才算进"未使用的文件"，删除时照旧要确认。自己的文件在 Aji 的文件夹之外，永远不删。

4. 引擎控制台

一个面板，默认不在任何布局里，从配置菜单打开时加到右栏底部。显示 KataGo 的日志（stderr）、Aji 自己的记录、以及分析协议的发送和接收。长的回复只显示开头 400 字，可以展开。底部可以输入 JSON 查询，Aji 自动补上 id，回复只出现在控制台。会结束 Aji 自己分析的命令（terminate_all，以及终止非控制台的查询）会被拒绝并说明原因。协议内容只在控制台打开时记录，关着时不占用开销。
